## Что исправлено

Автообновление Raspberry больше не считается разрешением прервать шоу. `auto_apply=True` скачивает и проверяет релиз, но `apply_release_safely` вызывается только если blackout уже включён. Проверка повторяется непосредственно перед сменой сцены. Если за это время blackout сняли, сцена остаётся прежней, движок и вывод не меняются. Обычный sync не включает blackout. Пока идёт смена, supervisor venue не вооружает вывод. После смены в уже безопасном состоянии venue-ready может вернуться только под blackout.

Черновик рабочего стола пишется в `drafts/<scene>/`, а не через живые `PUT /api/config/*`. Сохранение patch больше не меняет engine и не переключает выход на Mock. `base_version` берётся из ревизии, на которой черновик открыт. Поиск `MAX(version)` перед отправкой убран. Конфликт и ошибка публикации не подменяют черновик. Правка во время уже идущей публикации остаётся черновиком.

Повторная публикация старых байтов через workspace не понижает `desired_version` выбранной установки. Явный откат остаётся отдельным назначением.

Проверка сцены идёт через YAML-парсер и в облаке, и в Python. Flow и quoted YAML не обходят пересечение адресов и требование целого адреса. Канон ORNG BAR этим проверкам соответствует (0 ошибок). Невалидная сцена не становится latest.

Локация читается по `GET /admin/locations/:id/scene-workspace` без живой Pi. Исполнитель — только явная привязка или Raspberry. Первый ноутбук не выбирается.

Калибровка по общему `cloud:http` больше не принимается. Команды идут в websocket вкладки и считаются успешными только после `applied`. Чужая сессия и поздний `set` после завершения сессию не поднимают. Сохранение калибровки на рабочем столе идёт в общий черновик. Облачный просмотр пресета подписан «Зразок палітри», а не как воспроизведение эффекта. Art-Net при таком просмотре не открывается.

Пульт не переписывался.

Страница «Калібрування» по-прежнему открывает `/setup`. Десятишаговый мастер там скрыт, но из файла не убран. Отдельной страницы калибровки без этого мастера в этом проходе нет.
