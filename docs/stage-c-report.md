Дата: 2026-10-27. Коммит, push и stable не делались. Световой тест не проводился.

## Что исправлено

- Обычный запуск больше не завершает чужой процесс на порту. Если порт занят не нашим процессом, запуск останавливается.
- Повторный запуск, если `/api/health` уже готов, только открывает пульт и не поднимает вторую копию.
- Без явного `-LocalOutput` ярлык не настраивает Ethernet и не включает локальный Art-Net. Отправку оставляет Raspberry. Потеря связи этот выбор не переключает.
- Явный локальный вывод по-прежнему доступен только флагом `-LocalOutput`. Wi-Fi и маршрут по умолчанию скрипт не меняет.
- Если `ORNG_DESKTOP_OUTPUT=raspberry`, API отклоняет локальную активацию Art-Net.
- Статусы шапки: «Готово», «Очікуємо контролер», «Перепідключення», «Потрібна увага».
- Установщик ярлыка на managed-приложение отказывается работать, пока нет `current.json` и runtime релиза. Текущий ярлык не переключался.
- macOS-скрипт `macos-product.sh` прямо говорит: это не установленное приложение и не VERIFIED.
